Almost done — one manual step remains.

macOS will not let a background task read your Downloads folder until you say so, and Apple provides no way for an installer to request this for you.

Grant Full Disk Access

  1. Open System Settings → Privacy & Security → Full Disk Access
  2. Click +
  3. Press Cmd–Shift–G and enter /bin/zsh
  4. Add it, then switch it on

Or just run heic-converter grant-access in Terminal, which opens that pane directly.

The permission has to go to /bin/zsh rather than to this tool specifically, because that is the interpreter macOS sees running the watcher. That is the finest granularity this mechanism allows.

Then try it: drop a .heic file into Downloads. A converted copy should appear within a couple of seconds.

Choosing settings

Out of the box this converts to both PNG and JPG at 90% quality, watching your Downloads folder. To change any of that with a native picker, run:

heic-converter setup

It asks for the output format, then JPEG quality (only if you picked JPG or Both), then lets you browse to a different folder to watch.

Useful commands

  • heic-converter setup — format, quality, and watch folder
  • heic-converter format both — switch between png, jpg, or both (takes effect immediately, no reinstall)
  • heic-converter quality 90 — JPEG quality, 0–100
  • heic-converter watch-folder ~/Pictures — watch somewhere else
  • heic-converter doctor — diagnose it if nothing is converting
  • heic-converter run — convert everything already in the folder
  • heic-converter uninstall — remove it completely

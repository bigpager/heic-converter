Almost done — one manual step remains.

macOS will not let a background task read your Downloads folder until you say so, and Apple provides no way for an installer to request this for you.

Grant Full Disk Access

  1. Open System Settings → Privacy & Security → Full Disk Access
  2. Click +
  3. Press Cmd–Shift–G and enter /bin/zsh
  4. Add it, then switch it on

The permission has to go to /bin/zsh rather than to this tool specifically, because that is the interpreter macOS sees running the watcher. That is the finest granularity this mechanism allows.

Watching a folder outside Downloads, Desktop, or Documents — say ~/Pictures/Incoming — needs no permission at all, because those locations aren’t protected.

Changing settings

A HEIC Converter app has been added to your Applications folder. Open it any time to switch PNG and JPG on or off, set JPEG quality, or browse to a different folder to watch. It should have opened already.

Out of the box this converts to both PNG and JPG at 90% quality, watching your Downloads folder. Changes apply immediately — there is nothing to restart and no need to reinstall.

Then try it: drop a .heic file into the watched folder. A converted copy should appear within a couple of seconds.
